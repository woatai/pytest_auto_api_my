### 具体实施步骤

#### 1. product_detail 步骤实现
**目标**：从商品详情响应中提取第一个可用库存（stock > 0）的 unique

**YAML 配置** (`data/order_main_flow.yaml`)：
```yaml
product_detail:
  host: ${{host()}}
  url: /product/detail/${{product_id}}
  method: get
  headers:
    Content-Type: application/json;charset=UTF-8
    Authorization: Bearer ${{token}}
  assert:
    status_code: 200
    msg:
      jsonpath: $.msg
      type: in
      value: success
    has_stock:
      jsonpath: $.data.productValue[*].stock
      type: exists
  extract:
    unique: $.data.productValue  # 特殊处理：需遍历查找 stock>0 的 unique
```

**测试方法增强** (`test_case/test_order_main_flow.py`)：
```python
@allure.story("商品详情")
def test_product_detail(self):
    raw_case = get_case_by_id(yaml_name, "product_detail")
    case = resolve_placeholders(raw_case)
    
    host = case["host"]
    url = case["url"]
    method = case["method"]
    headers = case.get("headers")
    
    resp = RequestControl().send_request(
        method=method, host=host, url=url, headers=headers
    )
    
    # 断言
    AssertControl(assert_data=case.get("assert"), response=resp).run()
    
    # 复杂提取：遍历 productValue 找 stock>0 的 unique
    body = resp["body"]
    product_value = body.get("data", {}).get("productValue", {})
    unique = None
    
    for key, item in product_value.items():
        if isinstance(item, dict) and item.get("stock", 0) > 0:
            unique = item.get("unique")
            break
    
    if not unique:
        raise AssertionError("没有可用库存，无法下单")
    
    ContextManager.set("unique", unique)
    print(f'提取变量unique：{unique}')
```
